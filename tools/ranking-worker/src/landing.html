Up and running in two minutes.

1

Download and unzip

Right-click the ZIP → “Extract All”. Don't start it from inside the ZIP.

2

Run the installer

Double-click “PeakMeter installieren.cmd”. If Windows warns you: “More info” → “Run anyway”.

3

Install Npcap if asked

Its download page opens by itself. The default settings are fine.

4

Start before you log in

Then PeakMeter knows names, pets and energy from the first second.

Reads. Never touches.

PeakMeter only reads your own game's network traffic. No memory access, nothing is sent to the game, and it updates itself from GitHub. Third-party tools may still be against the terms of service, so use it at your own risk.
